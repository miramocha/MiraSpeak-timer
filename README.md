# Timer

MiraSpeak module. Says a phrase on a timer, using the voice bar on its page.

Needs MiraSpeak with module API 1.

## Install

In MiraSpeak, open **Integrations → Modules → Install from GitHub** and paste:

https://github.com/miramocha/MiraSpeak-timer

Leave the ref blank for the default branch, or enter `v0.1.0`.

It asks for **speak** and **MCP tools**. A Python module runs inside MiraSpeak with the same access as the app.
